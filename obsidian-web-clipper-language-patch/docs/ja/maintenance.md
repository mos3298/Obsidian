# 更新と公式への提案

## このリポジトリの更新方針

このパッチは対応する公式commitを固定して管理します。公式のmainが変わっても、ローカル版へ自動では反映されません。

更新時は以下を確認します。

1. 公式に同等の修正が取り込まれていないか確認する。
2. 新しい公式commitでDefuddle生成箇所と字幕言語の伝播を再確認する。
3. 別の作業フォルダーでパッチを適用し、競合があれば現在のソースに合わせて修正する。
4. 言語選択テスト、ビルド、実動画と主要機能の回帰確認を行う。
5. READMEの対応commit、パッチ、検証結果、CHANGELOGを同時に更新する。

パッチが機械的に適用できることと、正常に動作することは別です。未検証の最新版を対応済みと記載しません。

英語版と日本語版のコマンド・対応バージョン・検証済み／未検証の区別を揃えて更新します。

## インストール済みローカル版の更新

1. ローカル版の設定をエクスポートしてバックアップする。
2. 新しい対応版をビルドする。
3. Chromeが現在読み込んでいる `dist` を、新しいビルド内容へ更新する。
4. Chromeの拡張機能一覧でローカル版の再読み込みを押す。
5. 対象ページも再読み込みして動作を確認する。

同じパスから読み込んだ拡張を再読み込みすれば、通常は設定が維持されます。読み込み元フォルダーを移動したり、拡張を削除して追加し直したりすると扱いが変わる可能性があるため、バックアップを保存してください。

## 公式へのPull Request

このパッケージを置く `mos3298/Obsidian` は、公式リポジトリのForkではありません。公式へのPRは、別途 `obsidianmd/obsidian-clipper` のForkを作り、その作業ブランチへ変更を反映して提出します。

提案では以下を説明します。

- 原因: Defuddleにブラウザーの希望言語が渡されていないこと。
- 変更: 拡張の7か所に共通関数で言語を渡す最小修正。
- 関連Issue: [#957](https://github.com/obsidianmd/obsidian-clipper/issues/957)。
- 自動テスト、変更前から存在する失敗、未確認項目。

日本語専用機能ではなく、ブラウザー言語を尊重する一般的な修正として提案します。採用・実装方針・リリース時期は公式メンテナーが判断します。

公式版に修正が入ったら、そのバージョンへの移行を案内し、このパッチが不要になったことをREADMEへ追記します。
